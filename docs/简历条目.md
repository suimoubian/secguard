## 版本二:三条(推荐,大多数简历用这个)

> **SecGuard — 高性能安全审计引擎**(C++20 / CMake / MySQL / Redis / Docker)
>
> - 手写 **AC 自动机**(Trie + BFS 建 fail + 转移补全)做多模式实时匹配:
>   234 条特征下比朴素逐串匹配快 **52 倍**(1000 条特征时 4.96μs vs 260μs),
>   验证方式为 **15000 次随机对拍 + ASan/UBSan**,零差异零报错
> - 设计**无锁 MPSC 队列 + 后台批量落库**的审计管道:
>   相比同步写库吞吐从 281 提升到 **36520 QPS(130 倍)**
> - 基于 Redis + Lua 实现**分布式限流/封禁/重放防护**(带单机降级),
>   并把封禁检查与令牌桶合并为一次 Redis 往返、连接改为线程局部,
>   压测驱动下吞吐从 20627 优化到 **35070 QPS(P99 15ms → 7.7ms)**
>
> *整套服务 Docker Compose 一键部署(nginx/app/mysql/redis,约 420MB 内存)。*

## 版本三:五条(项目单独占一段时)

> **SecGuard — 高性能安全审计引擎** | C++20 / CMake / MySQL 8 / Redis / Nginx / Docker
>
> - **核心算法**:手写 AC 自动机(Trie + BFS 建 fail + 缺失转移补全,定长 256
>   转移表按字节匹配),234 条攻击特征一次扫描全命中;1000 条特征下单次匹配
>   4.96μs,比朴素逐串匹配快 **52 倍**;15000 次随机对拍 + sanitizer 零问题
> - **高并发架构**:多线程 HTTP 服务 + 连接池(RAII 借还、探活)+
>   **无锁 MPSC 环形队列**做审计管道,吞吐相比同步落库提升 **130 倍**
> - **分布式防护**:Redis + Lua 实现原子令牌桶限流、IP 自动封禁、nonce 重放防护;
>   Redis 不可用时自动降级单机版而不阻断服务;压测定位出"每请求两次往返 +
>   连接池锁争用"两个瓶颈,优化后 20627 → **35070 QPS**
> - **安全工程**:PBKDF2-HMAC-SHA256(每用户随机盐)口令存储、HS256 JWT、
>   全链路预编译参数化查询;LLM 分析层做了**抗提示注入**(不可信数据定界 +
>   定界符剔除 + 结构化校验),并端到端验证清洗生效
> - **可观测与交付**:全环境变量配置并启动校验、四档日志含字段级脱敏、
>   `/health` 真实探测数据库、优雅停机落盘审计队列、Docker 多阶段构建 +
>   Compose 一键部署,2 核 3.6 万 QPS / P99 8.3ms

## 版本四:项目 A(绕过评测 + 归一化层,单独占一段时用)

> **SecGuard 检测引擎加固 — 绕过评测与归一化层**(C++20)
>
> - **先量化再改**:自建 169 条标注语料(39 条基线 / 82 条变形 / 48 条正常,
>   覆盖 37 种绕过手法),用"基线命中、变形漏掉"作为绕过的严格定义,
>   测出原引擎在编码变形上的漏报率 **61.0%**(根因:检测链路对 QUERY/BODY 不解码)
> - **设计双遍检测**:"原始遍(零回归)+ 归一化遍(百分号/实体/JS 转义解码、
>   块注释折叠、空白压缩、NUL 剔除)"取并集,漏报率降到 **6.1%**,
>   误报仅 **+2.1pp**(其中 8/9 条是原有规则过宽的存量问题)
> - **归一化的收益是"收敛"而不是"猜"**:把无穷多种编码变形收敛成有限形状,
>   一条规则即可覆盖整族(`java\nscript:` / `java\tscript:` / `java%20script:`
>   → `java script:`);代价 **+0.37 µs/请求**(按 3.6 万 QPS 约 1.4% 单核)

## 数字口径(面试被问"怎么测的"时照这个答)

| 数字 | 口径 |
|---|---|
| 52 倍 | 文本 2079 字节、1000 条特征、Release -O2、每档 2000 次取平均 |
| 36520 QPS / P99 8.29ms | wrk,64 连接 10 秒,服务 taskset 绑 2 核,含每请求审计落库 |
| 130 倍 | 同一条件下:异步队列 vs 每请求同步 INSERT |
| 35070 QPS | 合并 Redis 往返 + 线程局部连接后的多轮中位数 |
| 实测环境 | i7-13650HX 笔记本 + WSL2;**数字应在目标服务器复跑** |
| 61.0% → 6.1% | 169 条语料:39 基线(实测 100% 检出)+ 82 变形 + 48 正常;分母只算"基线命中"的变形样本;`./scripts/eval-waf.sh` |
| +0.37 µs/请求 | 引擎级微基准(单条请求约 60~200 字节的待检文本),不是 HTTP 级;端到端 wrk 复测未做 |
| 误报 +2.1pp | 48 条正常语料,8 → 9 条;新增的 1 条是 `%3Cinput` 解码后命中 `<input` |
